# @sectorone/sdk

Uniswap V2-style routing (factory, router, pairs) for [SectorOne](https://sectorone.xyz) on **Base** (chainId `8453`).

## Install

```sh
pnpm add @sectorone/sdk
```

Peer dependency: `viem >= 2.5.0`

## Develop

```sh
pnpm install
pnpm build
pnpm test
```
