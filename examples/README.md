# Examples

Reference TypeScript snippets for integrating SectorOne. These are **documentation** — not a runnable package in this repo.

Copy into your project after installing `@sectorone/sdk-core`, `@sectorone/sdk-v2`, and `viem`.

| File | Description |
|------|-------------|
| [swap-exact-in.ts](./swap-exact-in.ts) | Quote USDC → WETH and build router calldata |
| [list-lb-pairs.ts](./list-lb-pairs.ts) | Discover LB pairs for a token pair |
| [read-pair-state.ts](./read-pair-state.ts) | Active bin, reserves, fees |
| [dexlens-price.ts](./dexlens-price.ts) | USD price from DexLens |

Set `BASE_RPC_URL` before running adapted scripts.

See also [docs/cookbook.md](../docs/cookbook.md).
